# Late Unbalanced Bilinguals Dataset

This dataset contains structural and functional MRI data along with two functional localizer tasks for 119 late, unbalanced, Polish-English bilinguals.

The dataset includes anatomical T1 scans for each participant.

On top of anatomical images, for each participant the dataset includes functional scans and their corresponding fieldmaps for two functional localizer tasks:

Language localizer in L1 - based on the Alice in Wonderland task (Malik-Moraleda, Ayyash et al., 2022)
Multiple Demand network localizer - based on a visual working memory task (Fedorenko et al., 2013)

Details of the functional localizer tasks are described in:
https://direct.mit.edu/nol/article/5/2/315/118227
https://www.nature.com/articles/s41598-023-49375-9
